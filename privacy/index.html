robin-klipp-verktyg – Privacy Policy

Last updated: 13 November 2026

Summary

robin-klipp-verktyg is a private tool run on Robin Hellgren's own computer. It does not sell, share or analyse personal data.

Data from TikTok

When a TikTok account connects, the tool receives:

  • basic profile information (user.info.basic), to show which account is connected
  • an access token and a refresh token, to upload drafts (video.upload)

The tokens are stored only on Robin's computer, in a file only the owner can read. They are never logged or sent anywhere except to TikTok.

Videos

Videos are made from Twitch streams and are uploaded only to the connected account's TikTok inbox as drafts.

Sharing

No data is shared with third parties, except TikTok itself when a draft is uploaded.

Deleting data

Disconnect in the tool, or remove the app in TikTok settings. The tool then deletes its tokens and revokes access.

Contact

Robin Hellgren, via the TikTok developer account for this app.
