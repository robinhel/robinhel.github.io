What this is

robin-klipp-verktyg is a private tool used by one person, Robin Hellgren. It turns Twitch streams into short vertical clips. With the user's permission, it uploads clips as drafts to the user's TikTok inbox.

Who may use it

Only Robin and TikTok accounts that Robin owns or manages. The tool is not offered to the public and is not sold.

TikTok

The tool uses TikTok Login Kit and the Content Posting API (scope video.upload). It only uploads drafts. The user reviews and posts each video in the TikTok app. The tool never posts without the user.
